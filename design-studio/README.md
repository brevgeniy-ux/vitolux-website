# Vitolux Design Studio

Сервис для создания дизайн-проектов квартир и домов с 3D-визуализацией. Работает в браузере, проекты хранятся локально (IndexedDB), сервер нужен только для AI-режима и раздачи сборки.

## Что умеет

| Этап | Возможности |
|---|---|
| **ИИ-дизайнер (чат)** | Встроенный Claude ведёт проект в диалоге: принимает скриншоты понравившихся интерьеров (Pinterest, фото — вставка Ctrl+V или перетаскивание), разбирает стиль, цвета и материалы, задаёт вопросы, рекомендует и сам вносит изменения: стиль и своя палитра, планировка, отделка стен и полов, мебель, свет, параметры объекта. Предлагает варианты, каждый создаётся отдельным проектом. Следит за полнотой данных: если, например, на плане нет высоты потолков, спросит о ней |
| **Материалы прежнего дизайнера** | Загрузка всего, что осталось (PDF-альбомы, планы, коллажи, визуализации, тексты). PDF разбирается на страницы и текст. ИИ изучает материалы, находит страницу с планировкой и распознаёт её, продолжает концепцию, переносит палитру, доделывает мебель и свет, перечисляет, что было сделано и чего не хватало, задаёт вопросы и предлагает альтернативы |
| **Своя планировка** | Загрузка плана заказчика в PDF или изображением (чертёж БТИ, план застройщика, скан, фото, рисунок от руки; для дома — по странице на этаж). Claude распознаёт помещения, двери и окна, стены соседних помещений автоматически стыкуются. Если ИИ недоступен или не может смотреть изображения, план распознаётся без ИИ, по линиям чертежа: стены, замкнутые помещения, масштаб и названия из таблицы экспликации в PDF, двери и окна расставляются автоматически. Изображение остаётся подложкой под планом (рамка вокруг самого плана на листе): масштаб калибруется по известному размеру, подложку можно сдвигать и обводить вручную |
| **Планировка** | 4 типовые планировки (1/2/3-комнатная, дом в 2 этажа), генератор по списку помещений, AI-бриф (Claude), ручное черчение: помещения, двери, окна, притягивание к соседним стенам, несколько этажей |
| **Мебель** | Каталог из 30 позиций (мягкая и корпусная мебель, кухни, сантехника, техника). Авторасстановка по эргономике: учитывает двери, окна и зоны прохода |
| **Стиль и отделка** | 6 стилей (скандинавский, минимализм, лофт, неоклассика, джапанди, современный) и своя палитра проекта; 14 видов отделки стен (покраска, декоративная штукатурка, микроцемент, обои, кирпич, реечные панели, панели с молдингами, плитка, зеллиж, мрамор, травертин) с акцентной стеной; 11 напольных покрытий; всё с текстурами в 3D и ценами в смете |
| **Освещение** | Каталог светильников Vitolux, авторасчёт по нормам освещённости (метод коэффициента использования, ДБН В.2.5-28), декоративный свет по стилю: люстры, подвесы, треки, бра, торшеры, LED-ленты |
| **3D** | Three.js / React Three Fiber: тени, день и вечер, виды из помещений (камера выбирает свободный угол), срез стен, все этажи, рендер в высоком разрешении, экспорт **GLB** для Blender, SketchUp и 3ds Max |
| **Документация** | Альбом листов А4 со штампом: титул, концепция и палитра, обмерный план, план мебели, план освещения со светотехническим расчётом, план полов, экспликация и ведомость отделки, спецификации, смета, визуализации. Сохранение в **PDF** через печать, смета в **CSV** (Excel), проект в **JSON** |

## Запуск

```bash
cd design-studio
npm install
npm run dev          # фронтенд http://localhost:5180 + API http://localhost:8787
```

Production (одна команда, один порт):

```bash
npm run build
npm start            # http://localhost:8787
```

Docker: `docker compose up design-studio` из корня репозитория.

### AI-бриф (необязательно)

Скопируйте `.env.example` в `.env` и укажите `ANTHROPIC_API_KEY`. Сервер передаёт бриф модели Claude (по умолчанию `claude-opus-5`, можно сменить через `CLAUDE_MODEL`). Модель возвращает стиль, программу помещений и текст концепции в виде структурированного JSON. Планировку, мебель и свет затем строит детерминированный генератор. Если модель откажется отвечать, запрос автоматически повторится на резервной модели (параметр `fallbacks: "default"`). Тот же ключ используется для ИИ-дизайнера в чате, анализа материалов и распознавания планировок (`/api/ai`). Без ключа всё остальное работает, а загруженный план можно обвести вручную.

## Управление

| Действие | Клавиша / жест |
|---|---|
| Выбор / Помещение / Дверь / Окно | `V` / `M` / `D` / `W` |
| Повернуть предмет | `R` (`Shift+R` — в обратную сторону) |
| Сдвиг | стрелки (`Shift` — шаг 0,5 м) |
| Дублировать | `Ctrl+D` |
| Удалить | `Delete` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Y` |
| Масштаб / сдвиг плана | колесо / `Shift`, средняя или правая кнопка мыши + перетаскивание |

## Структура

```
src/
  data/        каталоги: помещения и нормы, стили, покрытия и расценки, мебель, светильники
  lib/         геометрия, шаблоны и генератор планировок, авторасстановка мебели,
               светотехнический расчёт, смета, IndexedDB, AI-клиент
  three/       3D-сцена, процедурные модели мебели и светильников, текстуры
  components/  2D-план и редактор, панели, 3D-вид, альбом документации, мастер проекта
server/        Node-сервер: /api/health, /api/concept, /api/ai (универсальный запрос к Claude: диалог + изображения + JSON-схема), раздача dist
scripts/       build-artifact.mjs — сборка в один HTML для публикации на claude.ai
```

Расценки и цены в `src/data/*.ts` ориентировочные (грн). Их можно заменить на актуальные или подтягивать из каталога магазина (`backend/`).
