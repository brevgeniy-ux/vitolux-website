# Инструкция по установке мессенджера заявок на Mac

Делаем по шагам, сверху вниз. Один шаг занимает от минуты до десяти.
Всего понадобится около часа, большая часть времени уйдёт на ожидание.

Что получится в итоге: на вашем Mac работает собственный мессенджер.
На телефоне одно приложение Element. Внутри вкладки по проектам
(Норма Костинг, Наос и другие). В каждой вкладке заявки приходят от бота проекта.

---

## Шаг 1. Домен: куда будут ходить телефоны

Нужен адрес вида `chat.ваш-домен.ua`. Используем любой домен, который у вас уже есть.

1. Узнаём внешний IP вашего интернета. На Mac откройте браузер, зайдите на **https://api.ipify.org** и перепишите цифры вида `91.xxx.xxx.xxx`.
2. Откройте в браузере личный кабинет регистратора домена (где вы покупали домен: например, nic.ua, ukraine.com.ua, hostpro.ua, GoDaddy, Cloudflare).
3. Найдите домен в списке и нажмите на него. Ищите раздел **«DNS»**, **«DNS-записи»** или **«Управление зоной»**.
4. Нажмите **«Добавить запись»** и заполните:
   - Тип: **A**
   - Имя (или «Хост», «Субдомен»): **chat**
   - Значение (или «Указывает на», «IP»): цифры из пункта 1
   - TTL: оставить как есть
5. Нажмите **«Сохранить»**. Если у вас Cloudflare, у записи выключите оранжевое облачко (режим «DNS only»).

Если IP у вашего провайдера меняется (динамический), подключите у провайдера услугу «Статический IP». Обычно это 30–60 грн в месяц и один звонок или одна кнопка в личном кабинете провайдера. Это сильно упростит жизнь.

## Шаг 2. Роутер: пропустить телефоны к Mac

1. Узнайте локальный адрес Mac: **Меню Apple → Системные настройки → Сеть → Wi-Fi (или Ethernet) → Подробнее**. Нужен «IP-адрес» вида `192.168.x.x`.
2. В браузере откройте адрес роутера. Обычно это **http://192.168.0.1** или **http://192.168.1.1** (напечатан на наклейке снизу роутера вместе с логином и паролем).
3. Войдите. Найдите раздел с одним из названий: **«Переадресация портов»**, **«Port Forwarding»**, **«Виртуальные серверы»**, **«NAT»**.
4. Добавьте два правила (кнопка **«Добавить»**):

   | Название | Внешний порт | Внутренний порт | Протокол | Внутренний IP          |
   |----------|--------------|-----------------|----------|------------------------|
   | chat-80  | 80           | 80              | TCP      | адрес Mac из пункта 1  |
   | chat-443 | 443          | 443             | TCP      | адрес Mac из пункта 1  |

5. Нажмите **«Сохранить»** или **«Применить»**.
6. Чтобы адрес Mac не поменялся после перезагрузки, в том же роутере найдите **«DHCP»** → **«Резервирование адресов»** (или «Static Lease», «Привязка IP к MAC») и закрепите за Mac его текущий адрес.

Если в меню роутера не находите нужное, напишите мне модель роутера (с наклейки), дам точный путь.

---

## Шаг 3. Mac не должен засыпать

1. **Меню Apple → Системные настройки → Экран блокировки**: «Выключать дисплей при питании от сети» поставьте любое значение, это не мешает.
2. **Системные настройки → Батарея** (или **Экономия энергии** на настольном Mac) → **Параметры** → включите **«Предотвращать автоматический переход в режим сна при выключенном дисплее»**. На MacBook также включите «Включать при доступе к сети».
3. **Системные настройки → Основные → Вход в систему** (или «Объекты входа»): сюда позже сам добавится OrbStack.

---

## Шаг 4. Установить OrbStack (это и есть «Docker» для Mac)

1. В браузере откройте **https://orbstack.dev** и нажмите **«Download»**. Выберите **Apple Silicon**.
2. Откройте скачанный файл `.dmg`, перетащите значок **OrbStack** в папку **Программы**.
3. Запустите **OrbStack** из папки Программы. При первом запуске нажмите **«Open»**, затем **«Docker»** на экране выбора, и разрешите, если macOS попросит пароль.
4. В окне OrbStack нажмите на шестерёнку (**Settings**) → **General** → поставьте галочку **«Start at login»**.
5. Можно закрыть окно, OrbStack останется работать в строке меню (значок сверху).

## Шаг 5. Скачать файлы мессенджера

1. Откройте программу **Терминал**: нажмите **Cmd + Пробел**, напечатайте `Терминал`, нажмите **Enter**.
2. Скопируйте строку ниже целиком, вставьте в Терминал (**Cmd + V**) и нажмите **Enter**:

   ```
   git clone https://github.com/brevgeniy-ux/vitolux-website.git ~/vitolux-website
   ```

   Если macOS предложит установить «инструменты разработчика», нажмите **«Установить»**, дождитесь конца и повторите команду.

   Если файлы ещё не влиты в основную ветку, после этого выполните:

   ```
   cd ~/vitolux-website && git checkout claude/vigilant-knuth-sn67cf
   ```

## Шаг 6. Запустить установку (один раз)

В том же Терминале вставьте и нажмите **Enter**:

```
cd ~/vitolux-website/matrix && ./setup.sh
```

Мастер задаст вопросы, отвечайте и нажимайте **Enter**:

1. **Домен**: например `chat.ваш-домен.ua` (то, что настроили на шаге 1).
2. **E-mail**: ваш, писем не будет, это требование выдачи сертификата.
3. **Логин администратора**: латиницей, например `evgeniy`.
4. **Пароль**: придумайте или просто нажмите Enter, мастер сгенерирует.
   Мастер покажет логин и пароль. **Сфотографируйте или запишите.**
5. **Проекты**: вводите название («Норма Костинг»), затем короткое имя латиницей (`norma-costing`). Повторите для каждого проекта. Когда проекты закончились, на вопрос о названии просто нажмите **Enter**.

Дальше мастер всё сделает сам (5–10 минут, идёт скачивание). В конце напечатает:

- адрес мессенджера;
- для каждого проекта **URL для заявок** и **секрет**. Это то, что вставляется в ваши системы. **Сохраните в заметки.**

Если мастер пишет предупреждение про DNS, значит шаг 1 ещё не «доехал». Подождите 10–15 минут и запустите `./setup.sh` снова.

## Шаг 7. Проверить в браузере

1. В браузере на Mac откройте **https://chat.ваш-домен.ua**.
2. Нажмите **«Войти»** (Sign in). Введите логин и пароль администратора из шага 6.
3. Слева должны быть вкладки с вашими проектами. Внутри каждой комната **«Все заявки»**.

---

## Шаг 8. Телефон

1. Установите **Element** из App Store (iPhone) или Google Play (Android). Полное название: *Element - Secure Messenger*.
2. Откройте, нажмите **«Войти»** (Sign In). Вместо `matrix.org` нажмите **«Изменить»** (Edit) рядом с названием сервера и введите `chat.ваш-домен.ua`, нажмите **«Продолжить»**.
3. Введите логин и пароль. Разрешите уведомления.
4. Если Element предложит «Проверить сеанс» (Verify this session), выберите «Проверить с другого устройства» и подтвердите в браузере, где уже вошли. Или нажмите «Пропустить».

Для сотрудников: добавьте их командой ниже и перешлите им логин и пароль, которые напечатает мастер.

```
cd ~/vitolux-website/matrix && ./setup.sh add-project
```

(Мастер спросит, что добавить. Чтобы добавить сотрудника в существующий проект, откройте файл `bootstrap/projects.json` в TextEdit, впишите логин в `"members": ["ivan"]`, сохраните и выполните команду `docker compose run --rm bootstrap` в папке matrix.)

## Шаг 9. Подключить сайт VitoluxUA

1. Откройте в браузере админку сайта: **https://ваш-сайт/admin**, войдите.
2. Слева **«Налаштування»**.
3. Прокрутите до блока **«Власний месенджер (Matrix)»**:
   - **URL вебхука**: вставьте URL проекта `vitolux` из шага 6
   - **Секрет вебхука**: вставьте секрет
   - поставьте галочку **«Увімкнути сповіщення»**
4. Нажмите **«Зберегти»** внизу страницы.
5. Нажмите **«Надіслати тестове повідомлення»**. На телефоне в комнате проекта Vitolux должно прийти сообщение.

Если тестовое сообщение не приходит: один раз выполните в базе сайта SQL из `matrix/README.md`, раздел «Подключение этого сайта», и повторите.

## Шаг 10. Подключить остальные системы

Для каждого проекта у вас есть URL и секрет. Любая система, умеющая отправлять «вебхук» или «HTTP-запрос», подключается так:

- Адрес: URL проекта
- Метод: **POST**
- Заголовок: `X-Hook-Secret: ваш-секрет`
- Тело: JSON с полями заявки, например `{"fields": {"Имя": "...", "Телефон": "..."}}`

Tilda: «Настройки сайта → Формы → Webhook», вставить URL с ключом в адресе: `URL?key=секрет`.
n8n: узел **HTTP Request**, метод POST, Header Auth с именем `X-Hook-Secret`.
Для любой другой системы напишите мне, какой именно, дам точную настройку.

## Если что-то не работает

В Терминале, в папке `~/vitolux-website/matrix`:

| Команда                 | Что делает                                  |
|-------------------------|---------------------------------------------|
| `./setup.sh status`     | Показывает, какие части запущены           |
| `./setup.sh logs`       | Показывает, какие заявки проходили         |
| `./setup.sh update`     | Обновляет сервер до свежих версий          |
| `./setup.sh backup`     | Делает резервную копию в папку `backups`   |
| `./setup.sh`            | Запустить мастер ещё раз, ничего не ломает |

Скопируйте то, что написал Терминал, и пришлите мне.
